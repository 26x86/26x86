# 26x86-VenFire release policy

This repository contains user-space host tooling, self-authored AArch64
conformance guests, and reproducible QEMU research inputs. It is not a macOS
distribution and it does not include Apple firmware, guest disks, signed
personalization tickets, or a claim that macOS boots.

The normal package profile is the literal source assignment
`BUILD_PROFILE = "release"`. A private lab tree may instead be generated by
`tools/create_developer_tree.py`; that tree is explicitly marked
`developer-nonredistributable` and must never be relabelled as a release. The
PEP 517 backend rejects developer markers, symlinked profiles, duplicate or
non-literal assignments, and stale developer staging before it asks setuptools
to produce an artifact.

Host policy and guest trust checks remain active in lab mode. A developer host
bypass does not modify macOS files, bypass Apple signatures, or turn synthetic
guest execution into macOS boot evidence. Upstream QEMU files retain their
upstream license and notices; see `patches/QEMU-COPYING` and the patch
provenance documentation.
