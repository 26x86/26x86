# Acknowledgments & Credits

The 26x86 project is built upon decades of pioneering research and open-source contributions from the Hackintosh, macOS emulation, and firmware communities.

## Core Projects & Authors

| Project | Key Contributors | Focus |
|---------|------------------|-------|
| OpenCorePkg | Acidanthera (vit9696, Download-Fritz, savvas, et al.) | Industry-standard clean-room UEFI bootloader |
| OpenCore-Legacy-Patcher | Dortania (Dhinak G, Mykola Grymalyuk, khronokernel, et al.) | Community patcher for unsupported Apple hardware |
| OCLP T2 Branch | Albert Mueller | Initial experimentation with Apple T2 hardware enablement |
| Lilu & Kernel Extensions | Acidanthera team | Essential kernel patching framework and device drivers |
| PatcherSupportPkg & MetallibSupportPkg | Dortania contributors | Binary payloads and Metal bytecode tools |

## Research & Reference Projects

- **Syncretic:** Telemetrap and AAAMouSSE SSE4.2 emulation research.
- **parrotgeek1:** VMM boot patch configurations.
- **moraea / laobamac:** Legacy non-Metal graphics frameworks and patch research.
- **TrungNguyen1909:** `qemu-t8030` device tree and Apple Silicon virtualization reference architecture.
